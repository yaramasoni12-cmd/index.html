OSI & TCP/IP Models Architecture

بنەمای سەرەکی چۆنیەتی گواستنەوەی داتا لە نێوان ئامێرەکاندا لە ڕێگەی چینەکانەوە (Layers):

  • Application Layer: چینی سەرەوە کە بەرنامەکان و وێبگەڕەکان مامەڵەی لەگەڵ دەکەن (HTTP, DNS).
  • Transport Layer: بەرپرسە لە پاراستن و گەیاندنی دروستی پاکێجەکان (TCP vs UDP).
  • Network Layer: تایبەتە بە ناردنی داتا و دۆزینەوەی ناونیشانەکان (IP Addressing & Routing).
  • Data Link & Physical: چینی فیزیکی و کارتی تۆڕ (MAC Address & Cables).

IP Addressing & Subnetting Addressing

ناسنامەی ئامێرەکان لەسەر تۆڕی ناوخۆیی و جیهانی بۆ ئاراستەکردنی دروستی زانیارییەکان:

  • IPv4 vs IPv6: ناونیشانی 32-بیت بەرامبەر ناونیشانی پێشکەوتووی 128-بیت.
  • Public & Private IPs: جیاوازی نێوان ئایپی ناوخۆیی ماڵەوە/کۆمپانیا و ئایپی گشتی سەر ئینتەرنێت.
  • Subnet Masks: دابەشکردنی تۆڕە گەورەکان بۆ چەند ژێر-تۆڕێکی بچووکتر بۆ ڕێکخستن و پاراستن.

Routing & Switching Traffic Flow

ئەو ئامێر و پرۆسەیانەی کە داتا لە نێوان تۆڕە جیاوازەکاندا ئاراستە دەکەن:

[ هاتوچۆی داتا (Data Routing) ]
• Switch: بەستنەوەی ئامێرەکان لە ناو تۆڕێکی لۆکاڵی (LAN) دا.
• Router: گواستنەوەی پاکێجی داتا لە نێوان تۆڕە جیاوازەکان و ئینتەرنێتدا.
• Gateway: دەروازەی سەرەکی بۆ چوونە دەرەوەی تۆڕەکە.

Core Network Protocols Protocols

زمان و رێساکانی تێگەیشتنی ئامێرەکان لەگەڵ یەکتردا لەسەر تۆڕ:

  • TCP (Transmission Control Protocol): دڵنیابوونەوە لە گەیشتنی هەموو پاکێجەکان بێ ونبوون (Connection-oriented).
  • UDP (User Datagram Protocol): گواستنەوەی خێرای داتا بێ دڵنیابوونەوە لە گەیشتنی هەمووی (بۆ ڤیدیۆ و یاری).
  • DNS (Domain Name System): وەرگێڕانی ناو و ناونیشانی سایتەکان (وەک google.com) بۆ ئایپی ئامێر.

Network Defenses Security

چۆنیەتی پاراستنی تۆڕ لە دەستدرێژی دەرەکی و دزیکردنی زانیاری:

  • Firewalls (فایروۆڵ): پشکنی و بلۆککردنی هاتوچۆ نەخوازراوەکان بەپێی یاسا.
  • IDS / IPS: سیستەمی ئاگادارکردنەوە و ڕێگریکردن لە جووڵە گوماناوییەکان لە ناو تۆڕدا.
  • VPN (Virtual Private Network): کۆدکردنی هاتوچۆی داتا لە ڕێگەی تونێلێکی پارێزراوەوە بەسەر ئینتەرنێتدا.

Network Attacks & Risks Vulnerabilities

ئەو مەترسی و لاوازییە باوانەی کە ڕووبەڕووی تۆڕەکان دەبنەوە:

[ مەترسییە سەرەکییەکان ]
• Man-in-the-Middle (MitM): چاودێریکردن و دەستکاری کردنی هاتوچۆ لە نێوان دوو ئامێردا.
• Packet Sniffing: گوێگرتن و گرتنی پاکێجی داتا بەبێ ڕێگەپێدان.
• Port Scanning: گەڕانی هێرشبەران بەدوای دەرچە کراوەکاندا.

Computer Systems & OS Hardware/OS

بنەماکانی کارکردنی کۆمپیوتەر، پڕۆسێسەر و سیستەمی بەڕێوەبردن:

  • CPU Architecture: چۆنیەتی جێبەجێکردنی فەرمانەکان لە ڕێگەی ALU و Control Unit و Registers.
  • Memory Hierarchy: جیاوازی نێوان خێرایی RAM، Cache، و قەبارەی Storage (SSD/HDD).
  • Kernel & Processes: ڕۆڵی קרنڵ لە بەڕێوەبردنی ڕەقەکاڵا (Hardware) و پرۆسەکانی سیستەم (Processes & Threads).

Cryptography & Hashing Crypto

پاراستنی نهێنی زانیارییەکان لە ڕێگەی کۆدکردن و ئاڵۆزکردنی matematiki:

  • Symmetric Encryption: بەکارهێنانی هەمان کلیڵ بۆ قفڵکردن و کردنەوە (AES, DES).
  • Asymmetric Encryption: سیستەمی دوو کلیڵی عمومی و تایبەت (Public & Private Keys / RSA).
  • Hashing Algorithms: گۆڕینی دەق بۆ کۆدی نەگۆڕانەوە (SHA-256, MD5) بۆ دڵنیابوون لە پاکی داتا.

Web & App Security SecOps

پاراستنی سیستەمە ئەلیکترۆنییەکان و وێبسايتەکان لە لاوازییە مەترسیدارەکان:

[ لاوازییە باوەکانی OWASP Top 10 ]
• SQL Injection (SQLi): هێرشکردن بۆ ناو داتابەیس لە ڕێگەی خانەی نووسینەوە.
• Cross-Site Scripting (XSS): چاندنی کۆدی زیانبەخش لە ناو پەڕەی وێبدا.
• Broken Authentication: لاوازی لە سیستەمی چوونەژوورەوە و پاراستنی پاسوۆرد.

Ethical Hacking Lifecycle Offensive Sec

قۆناغەکانی پشکنی و دۆزینەوەی کون و کەلەبەرەکان پێش ئەوەی هێرشبەری ڕاستەقینە بیاندۆزێتەوە:

  • Reconnaissance & Footprinting: کۆکردنەوەی زانیاری سەرەتایی دەربارەی ئامانجەکە.
  • Scanning & Enumeration: دۆزینەوەی پۆرتە کراوەکان، ڤێرژنی خزمەتگوزارییەکان و لاوازییەکان.
  • Exploitation: تاقیکردنەوەی کونەبەرەکان بە ئامانجی دەستکەوتنی دەسەڵات (Access).
  • Reporting: نووسینی ڕاپۆرتی چارەسەرکردن بۆ پتەوکردنی سیستەمەکە.
